# Escopo do Projeto: Expense Control API

## Problema

Pequenas operações frequentemente controlam despesas em planilhas ou registros manuais, dificultando consulta, consolidação e validação dos dados.

## Solução

Uma API REST em Python para centralizar o cadastro de despesas, armazenar os dados em SQLite e disponibilizar consultas e relatórios por endpoint.

## Funcionalidades

- Cadastro de despesas.
- Listagem com filtros.
- Consulta individual.
- Remoção de registros.
- Relatório consolidado por categoria.
- Validação de campos obrigatórios, valores e datas.

## Entregáveis

- Código da API.
- Banco SQLite criado automaticamente.
- Documentação das rotas.
- Testes automatizados.
- Texto de apresentação comercial.

## Possíveis adaptações

- Autenticação de usuários.
- Exportação de relatórios em CSV.
- Integração com planilhas.
- Dashboard web.
- Deploy em servidor ou nuvem.
