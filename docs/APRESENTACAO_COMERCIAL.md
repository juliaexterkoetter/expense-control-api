# Apresentação Comercial

## Título

API de gestão de despesas com Python e SQLite

## Descrição

Este projeto implementa uma API REST para cadastro, consulta, exclusão e consolidação de despesas operacionais. A solução permite registrar despesas com categoria, valor, data e forma de pagamento, além de consultar os dados com filtros e gerar relatório consolidado por categoria.

O backend foi desenvolvido com Python e SQLite, usando bibliotecas nativas para facilitar execução e implantação em ambientes simples. O projeto inclui validação de dados, organização por camadas, persistência em banco de dados e testes automatizados.

Esse tipo de solução pode ser adaptado para controles financeiros internos, cadastros operacionais, painéis administrativos, sistemas de backoffice e integrações com outras ferramentas.

## Habilidades aplicadas

- Python
- Backend
- API REST
- SQLite
- Validação de dados
- Testes automatizados
- Relatórios operacionais
